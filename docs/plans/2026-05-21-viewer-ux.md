# Viewer UX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Improve the 3D viewer with a better default camera mode (orbit/rotate-base instead of fly), a Ctrl+M toggle between orbit and fly, a smarter initial zoom for large bases, and context-aware HUD tips for each mode.

**Architecture:** Replace `UniversalCamera` as default with `ArcRotateCamera` (Babylon's orbit camera — rotate around target, no pointer lock needed). Ctrl+M swaps between orbit and fly, tracking current mode in a ref. Zoom is fixed by computing camera distance from bounding-box diagonal instead of horizontal span. HUD tips live in a small component that reads current mode from a state value passed down from `SceneCanvas` via callback.

**Tech Stack:** Babylon.js 9 (`ArcRotateCamera`, `UniversalCamera`), React 19, TypeScript

### Task 2: Fix initial zoom for large bases

**Files:**
- Modify: `src/components/Scene/SceneCanvas.tsx`

The current formula uses `spanH / Math.tan(0.4)` which produces very large distances for big bases. Replace with a formula based on the 3D bounding-box diagonal and a fixed vertical FOV.

- [ ] **Replace zoom math in the auto-frame block**

Current:
```ts
const spanH = Math.max(maxX - minX, maxY - minY) + TILE * 2;
const dist  = (spanH / 2) / Math.tan(0.4) * 1.3 * initialDistanceScale;
const hDist = dist * Math.cos(Math.PI / 4);
const vDist = dist * Math.sin(Math.PI / 4);
startPos = new Vector3(cx + hDist, cy + vDist, cz - hDist);
```

Replace with:
```ts
const spanX  = maxX - minX + TILE * 2;
const spanY  = maxY - minY + TILE * 2;
const spanZ  = Math.max(...zs) - Math.min(...zs) + TILE;
const diag   = Math.sqrt(spanX * spanX + spanY * spanY + spanZ * spanZ);
// FOV ~60° → tan(30°) ≈ 0.577. Pull back enough to see the full diagonal.
const radius = (diag / 2) / Math.tan(Math.PI / 6) * 0.85 * initialDistanceScale;

startPos = new Vector3(cx + radius * 0.6, cy + radius * 0.5, cz - radius * 0.6);
```

And use `radius` as the `ArcRotateCamera` initial radius:
```ts
orbitCam.radius = radius;
```

- [ ] **Create ViewerHUD component**

```tsx
// src/components/Scene/ViewerHUD.tsx
interface Props {
  mode: 'orbit' | 'fly';
  locked: boolean;
  pieceSelected: boolean;
  isOwner: boolean;
}

export function ViewerHUD({ mode, locked, pieceSelected, isOwner }: Props) {
  const tips: string[] = [];

  if (mode === 'orbit') {
    tips.push('Left drag — rotate base');
    tips.push('Right drag — pan');
    tips.push('Scroll — zoom');
    tips.push('Click — select piece');
    tips.push('Ctrl+M — enter fly mode');
  } else if (!locked) {
    tips.push('Click to enter fly mode');
  } else {
    tips.push('WASD — fly');
    tips.push('Space / Shift — up / down');
    tips.push('Click — select piece');
    tips.push('Esc — exit fly mode');
    tips.push('Ctrl+M — return to orbit');
  }

  if (pieceSelected && isOwner) {
    tips.push('R — cycle rotation override');
    tips.push('Shift+R — reverse cycle');
  }

  return (
    <div style={{
      position: 'absolute', bottom: 16, right: 16,
      color: 'rgba(255,255,255,0.35)',
      fontSize: 10,
      lineHeight: 1.9,
      textAlign: 'right',
      pointerEvents: 'none',
      userSelect: 'none',
    }}>
      {tips.map(t => <div key={t}>{t}</div>)}
    </div>
  );
}
```
